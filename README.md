# AI Food Ordering Agent

A conversational AI agent that handles food orders through natural language,
manages user preferences, and confirms transactions using multi-turn dialogue.

## Features
- Multi-turn conversation management
- Menu-based ordering with preference handling
- Order confirmation and summary generation
- Context-aware response generation

## Tech Stack
- Python
- LLM APIs
- Prompt Engineering
